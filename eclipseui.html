UI Library

Meet EclipseUI

A dark-purple Roblox Lua UI library with windows, tabs, sections, buttons, toggles, sliders, labels, and notifications.

Setup

Keep the library source in EclipseUI.lua at the root of your GitHub Pages repository. The file can be hosted without showing a link to it on your homepage.

GitHub Pages files are public. Removing a source link from the navigation does not protect the source from people who know its URL. Standard Roblox scripts also cannot freely execute arbitrary remote source with loadstring; availability depends on the authorized environment.

Once the library has been loaded in a compatible Lua environment, use the API below.

Create a window

local window = EclipseUI:CreateWindow({
    Title = "My Window"
})

local tab = window:CreateTab("Main")
local section = tab:CreateSection("Welcome")

section:CreateLabel("Hello from EclipseUI!")

Button

section:CreateButton({
    Name = "Click me",
    Callback = function()
        print("Button clicked!")
    end
})

Toggle

local toggle = section:CreateToggle({
    Name = "Example toggle",
    Default = false,
    Callback = function(value)
        print("Toggle:", value)
    end
})

print(toggle:GetValue())
toggle:SetValue(true)

Slider

local slider = section:CreateSlider({
    Name = "Walk speed",
    Min = 0,
    Max = 100,
    Default = 16,
    Callback = function(value)
        print("Slider:", value)
    end
})

print(slider:GetValue())

Label

local label = section:CreateLabel("Ready!")

label:SetText("Updated text")

Notifications

EclipseUI:Notify("Hello from EclipseUI!", 3)

The second argument is the notification duration in seconds.

API quick reference

  • EclipseUI:CreateWindow(options)
  • window:CreateTab(name)
  • tab:CreateSection(name)
  • section:CreateLabel(text) → SetText
  • section:CreateButton(options) → SetText
  • section:CreateToggle(options) → GetValue, SetValue
  • section:CreateSlider(options) → GetValue
  • EclipseUI:Notify(message, duration)
