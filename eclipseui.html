Lua UI Library

EclipseUI

A dark-purple Roblox Lua UI library with windows, tabs, sections, buttons, toggles, sliders, labels, and notifications.

🚀 Loading EclipseUI with loadstring

Use this loading pattern in a Lua environment that supports remote HTTP requests and loadstring. It fetches EclipseUI directly from the RawrHub GitHub repository.

local source = game:HttpGet(
    "https://raw.githubusercontent.com/rawrguy/rawrguy.github.io/main/EclipseUI.lua"
)

local EclipseUI = loadstring(source)()

-- Create your first window
local window = EclipseUI:CreateWindow({
    Title = "My EclipseUI Window"
})

local tab = window:CreateTab("Main")
local section = tab:CreateSection("Welcome")

section:CreateLabel("EclipseUI loaded!")
Requirements: The repository must use the main branch and contain EclipseUI.lua in its root. This pattern requires an environment that permits remote HTTP requests and dynamic code execution. Standard Roblox LocalScripts do not automatically support this pattern. Only load source code you trust.

🪟 Create a window

local window = EclipseUI:CreateWindow({
    Title = "My Window"
})

local tab = window:CreateTab("Main")
local section = tab:CreateSection("Home")

section:CreateLabel("Welcome!")

🔘 Button

section:CreateButton({
    Name = "Click Me",
    Callback = function()
        print("Button clicked!")
    end
})

🔀 Toggle

local toggle = section:CreateToggle({
    Name = "Example Toggle",
    Default = false,
    Callback = function(value)
        print("Toggle value:", value)
    end
})

print(toggle:GetValue())
toggle:SetValue(true)

🎚️ Slider

local slider = section:CreateSlider({
    Name = "Example Slider",
    Min = 0,
    Max = 100,
    Default = 50,
    Callback = function(value)
        print("Slider value:", value)
    end
})

print(slider:GetValue())

🏷️ Label

local label = section:CreateLabel("Hello!")

label:SetText("Updated label")

🔔 Notifications

EclipseUI:Notify("Hello from EclipseUI!", 3)

The second argument sets the notification duration in seconds.

📖 API Reference

  • EclipseUI:CreateWindow({Title = "..."})
  • window:CreateTab(name)
  • tab:CreateSection(name)
  • section:CreateLabel(text) — returns SetText
  • section:CreateButton({Name, Callback}) — returns SetText
  • section:CreateToggle({Name, Default, Callback}) — returns GetValue and SetValue
  • section:CreateSlider({Name, Min, Max, Default, Callback}) — returns GetValue
  • EclipseUI:Notify(message, duration)
